# 家居日用与平价首饰：询价和样品质检卡

## 共用询价字段

供应商必须一次性提供：含税/不含税单价、阶梯价、MOQ、打样费、包装后重量与尺寸、交期、
补货周期、瑕疵补发政策、可否一件代发、现货数量、图片/视频使用授权。无法书面确认的字段按高风险处理。

不要只问“最低价”。系统需要填写 `unit_cost_usd`、`outbound_shipping_usd`、`packaging_usd`、
`supplier_moq`、`lead_time_days`；缺任一成本时，商品只能停留在“询价/合规验证”。

## 家居日用

### 首轮禁入

- 带电、带电池、液体、易碎、大体积、食品接触、医疗/功效宣称商品
- 需要安装资质、存在儿童夹伤/吞咽风险或说明书高度复杂的商品
- 包装后重量和尺寸不明确、MOQ 高于 50、交期超过 20 天的商品

### 样品质检

1. 拍摄开箱全程，记录气味、毛刺、锐边、污渍和色差。
2. 按真实使用场景连续操作至少 30 次；承重品做逐级负载，不超出供应商书面标称。
3. 清洁后检查变形、掉色、开胶和残留气味。
4. 从桌面高度做包装状态跌落检查，确认运输后仍可销售。
5. 用手机在 3 秒内拍出“使用前/后”的清晰变化；否则内容分不得超过 60。

通过后将 `quality_evidence=true`，并记录 `weight_kg`、`longest_side_cm` 和 `content_score`。

## 平价首饰

### 首轮禁入

- 材质不明、供应商只写“合金精品”但拒绝给出基材与镀层
- 未有证据却宣称贵金属、天然宝石、抗过敏或永不褪色
- 儿童首饰，以及尺寸/佩戴方式容易造成高退货但没有清晰说明的款式
- MOQ 高于 50、交期超过 20 天的商品

### 供应商必须书面确认

- 基材、镀层/表面工艺、颜色、单件重量、尺寸和误差范围
- 是否含镍等潜在致敏信息；任何“低敏”文案都必须有可核验依据
- 正常佩戴与接触汗液后的保养要求、掉色和断裂售后政策
- 同批次色差控制、包装防刮方式、耳针/扣件等易损件备件

### 样品质检

1. 白光下拍摄正反面、焊点、扣件、边缘和镀层死角。
2. 扣件开合至少 100 次，检查松动、变形和刮手。
3. 分别做干布与湿布擦拭，记录掉色；按供应商说明进行连续佩戴观察。
4. 两件同款对比颜色、尺寸和重量一致性。
5. 佩戴视频必须真实呈现尺寸与颜色，不使用“纯金、天然、永不褪色、绝对低敏”等无证据表述。

只有材质说明与样品质检均留档后，才将 `quality_evidence=true`。检测要求和可用宣称最终应按
目标市场、平台规则及商品实际情况由合格专业人员核验。
